# Agus' Shelf

Agus' Shelf is a dark, responsive book-discovery experience built around the Open Library Search API.

## Features

- Search books while typing
- Open Library integration
- 20 results per request
- Load more pagination
- Responsive book grid
- Book detail dialog
- Loading, empty, and error states

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Tech

- Angular
- TypeScript
- RxJS
- SCSS
- Open Library API

## Notes

The project intentionally uses a small, direct architecture suited to a take-home exercise: standalone components, one search service, and local component state.
